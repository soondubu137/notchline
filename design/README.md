## 云端页面

- `Notch Core`：收起与共享展开核心几何；Expanded 参考基线为 `520 × 302`。
- `06 — Integration States`：隐私关闭、Unknown、额度不可用、监视生命周期、空和全局可用性状态。
- `07 — Onboarding`：首次安装 Welcome、本地集成授权与 Ready 三步流程。
- `08 — Settings`：Codex 集成管理与当前内容预览 On/Off。
- 全文件产品字体统一为 SF Pro。

## 本地 SVG

- `notch-core-compact-sonoma.svg`：带刘海屏幕的收起状态。
- `notch-core-expanded-sonoma.svg`：带刘海屏幕的展开状态。
- `fallback-core-compact-sonoma.svg`：无刘海屏幕的收起 fallback。
- `fallback-core-expanded-sonoma.svg`：无刘海屏幕的展开 fallback。

四张 SVG 是原始核心画板的可编辑导出。展开 SVG 仍保留旧 `444 × 310` 快照；最新几何、场景与文字规范以云端 Figma 为准。
